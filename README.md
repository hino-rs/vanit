# Vanit

## Policy

### 未成年禁止

- [ ] 自己申告NGで、第三者検証を必須にする
- [ ] 会話内容から未成年らしき発言を検知したら再認証を求める
- [ ] 定期的な顔照合の再認証を求め、なりすましを防ぐ
- [ ] 「未成年っぽい」と通報があった場合、双方に一時停止し再確認をかける

### 恋愛目的禁止

- [ ] 恋愛に発展する可能性があるプロフィール項目を持たせない
- [ ] 口説き文句、性的表現などを検知し、警告・アカウント制限
- [ ] 実際に会う約束につながる発言を検知した時点で警告
- [ ] 2回警告を受けたユーザーは永久的にBANする

### 個人情報・外部誘導の遮断

- [ ] 電話番号、SNSのID、メールアドレス、住所らしき文字を検知してブロック
- [ ] 「LINE交換しよう」「Instagram教えて」等のパターンを検知してブロック
- [x] GPS近傍マッチ、現在地共有機能は実装しない
- [ ] セクストーションを検知して永久BAN

### セッション構造

- [ ] 第一言語が同じ人とはマッチしない
- [ ] 同一ユーザー同士の再マッチは間隔が必要
- [ ] 1日当たりのマッチ数・1セッションの時間に上限をかける

### モデレーション・通報体制

- [ ] 自動検知でフラグが立った会話を運営で審査
- [ ] 通報された相手とは自動的に再マッチしない
- [ ] CSAM通報を整える
- [ ] 永久BANの実効性を高める

### 透明性

- [x] ソースコードの公開
